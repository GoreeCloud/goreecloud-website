Privacy at GoreeCloud

GoreeCloud is built around privacy by default. This statement describes the behavior of the public GoreeCloud website and the browser-side code maintained in this repository.

Last updated: August 15, 2026

Public website

No behavioral tracking.

This public website does not intentionally use analytics, advertising, behavioral tracking, third-party telemetry, fingerprinting, or third-party browser resources such as scripts, stylesheets, fonts, and rendered images. Browser-loaded site resources are kept on the GoreeCloud origin; external sites are reached only when you choose to follow a link.

Information collected by the website

The public site does not provide an account sign-in, web form, advertising profile, or marketing pixel. GoreeCloud's browser code does not create a behavioral profile of visitors or send browsing activity to an analytics service.

Appearance preferences

If you explicitly choose Light or Dark appearance mode, the site stores that choice in your browser under the goreecloud-theme key using localStorage. Returning to System mode removes the stored override. System mode requires no stored preference.

The appearance preference is used only by local GoreeCloud website code to select the visual theme; the site does not transmit that preference to an analytics or advertising service.

Hosting and network delivery

The public website is deployed through Cloudflare Pages. Delivering a web request necessarily uses hosting and network infrastructure, but this repository does not add analytics or advertising code that uses those requests to build a visitor profile.

This statement describes GoreeCloud's public website code and configuration. Services outside this repository, including destinations reached through external links, operate under their own policies.

Referrer privacy

GoreeCloud configures Referrer-Policy: no-referrer for the public site. This prevents the browser from intentionally sending the GoreeCloud page URL in the HTTP Referer header when you follow a link to another site.

External links and email

GoreeCloud links to public repositories and social profiles. When you leave GoreeCloud, the destination site's privacy practices apply. Email links on this site use mailto:; sending a message is handled by your email client and the email services involved, not by a GoreeCloud web form.

Security reports

Security vulnerability reports have a separate public reporting path. See the GoreeCloud security-reporting policy and /.well-known/security.txt before testing or reporting an issue.

Questions and changes

If the public website's privacy behavior changes materially, this statement should be updated with it. Questions about this statement can be sent to goreecloud@gmail.com.
