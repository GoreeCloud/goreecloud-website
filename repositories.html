Portfolio principle

Everything GoreeCloud builds belongs in source control.

GitHub is the current primary development platform. Repository visibility does not determine runtime maturity: public maintained-fork development can remain pre-production, and private repositories can serve active production roles. Each project's own specification and release evidence remain authoritative for deployment state.
