Wardveil Security by GoreeCloud

Responsible security reporting

I welcome good-faith reports about security vulnerabilities affecting public-facing GoreeCloud properties and publicly available software. Wardveil Security is GoreeCloud's platform-wide first-party security system and shared security plane. Its current Foundation 0.9 architecture includes scoped trust, policy, protection, detection, scanning, quarantine, response, audit, and Security Center capabilities while underlying applications, infrastructure, and authorized executors remain authoritative for the technical actions they own.

What to include

A useful report should contain enough detail to reproduce the issue safely.

  • The affected public GoreeCloud URL, repository, application, or version.
  • A clear vulnerability description and likely impact.
  • Minimal reproducible steps that avoid unnecessary harm.
  • Relevant request, response, log, screenshot, or proof-of-concept details with sensitive data removed.
  • Any remediation idea or mitigating condition already identified.

Testing boundaries

This policy does not authorize testing of private family infrastructure, private services, accounts, devices, internal networks, administrative interfaces, credentials, or non-public data. A public security policy is not permission to cross an access-control boundary.

  • Do not access, retain, modify, or disclose data that does not belong to you.
  • Do not perform destructive testing, denial-of-service activity, social engineering, credential attacks, or service disruption.
  • Do not use high-volume automated testing that could materially degrade a service.
  • Do not publicly disclose exploit details before there has been a reasonable opportunity to remediate the report.

Wardveil identity boundary

Sentinel Fold is the owner-approved standalone primary visual mark for Wardveil Security. The Wardveil Security name, Security Center label, and other wordmark text are supporting identity rather than part of the emblem itself. Neither the emblem nor the name is security evidence. Any explicit Wardveil protection status requires a defined scope, current authoritative evidence, and any applicable accepted runtime integration. A policy decision, successful transport, storage health, scanner branding, or Security Center screen cannot by itself prove that a protection action executed.

Malware-protection boundary

ClamAV is the initial replaceable signature-based malware engine beneath Wardveil Scan, not the Wardveil product boundary. A scanner result is interpreted through Wardveil's current evidence and health contracts. The production ClamAV runtime remains unaccepted until the required deployed scanner, authenticated application-consumer, quarantine-execution, and environment-specific acceptance evidence is complete; this page makes no blanket antivirus or Wardveil protection assurance.

How reports are handled

I will review credible reports and prioritize remediation according to impact, exploitability, exposure, and safety. GoreeCloud does not currently offer a bug bounty or guaranteed response timeline. This guidance does not create authorization to access systems, accounts, or data.
