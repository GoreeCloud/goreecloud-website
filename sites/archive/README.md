# GoreeCloud Archive

Public historical site planned for `archive.goreecloud.com`.

## Role

Preserve selected public milestones, architectural eras, product transitions, and the historical evolution of GoreeCloud.

The Archive is curated. It must not mirror internal change logs or expose credentials, private topology, operational details, personal information, historical sensitive data, or material that was never approved for public release.

## Cloudflare Pages

- Repository: `GoreeCloud/goreecloud-website`
- Root directory: `sites/archive`
- Build command: none
- Build output directory: `.`
- Production branch: `main`
- Custom domain: `archive.goreecloud.com`

The site is intentionally static and contains no analytics, advertising, remote fonts, or third-party browser runtime dependencies.
