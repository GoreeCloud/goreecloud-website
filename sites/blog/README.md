# GoreeCloud Blog

Public editorial site planned for `blog.goreecloud.com`.

## Role

Development articles, homelab lessons, project updates, architecture notes, privacy/security discussions, and other durable public GoreeCloud writing.

Internal operational records are not a public-content source by default. Articles derived from internal documentation must be deliberately selected and reviewed for sensitive information before publication.

## Cloudflare Pages

- Repository: `GoreeCloud/goreecloud-website`
- Root directory: `sites/blog`
- Build command: none
- Build output directory: `.`
- Production branch: `main`
- Custom domain: `blog.goreecloud.com`

The site is intentionally static and contains no analytics, advertising, remote fonts, or third-party browser runtime dependencies.
