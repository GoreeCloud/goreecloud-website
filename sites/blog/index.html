Platform

GoreeCloud is becoming a software ecosystem

The project now spans a growing Suite of native applications and maintained forks, connected by Glaze UI, Wardveil Security, Privacy Shield, Everkeep, GoreeCloud Identity, and shared interoperability rules. The goal is not to reproduce a commercial cloud vendor—it is to preserve ownership, portability, recoverability, and control.

Platform update · August 2026

Products

New first-party application families

Mail, Music, Photos, Tasks, DNS, Network, and Keyboard now have focused capability identities such as Courier, Resonance, Keepsake, Waypoint, Beacon, Conduit, and Quill. These names organize first-party feature systems without replacing the applications themselves.

Suite

Focused apps instead of one giant cloud

GoreeCloud is deliberately separating files, documents, photos, music, mail, tasks, calendars, contacts, notes, monitoring, networking, identity, and other responsibilities into focused products that can interoperate without becoming inseparable.

Design

Glaze UI 1.4 is now the stable design baseline

Glaze UI 1.4 is the current stable GoreeCloud design language, carrying deliberate form-factor adaptation across mobile, tablet, desktop, and TV while preserving shared semantics, accessibility expectations, and product consistency. Glaze UI 1.3 remains the supported older stable release.

Development

Fork when useful. Build native when it matters.

GoreeCloud uses open-source foundations pragmatically while steadily increasing first-party ownership of interfaces, capabilities, data contracts, release engineering, and long-term maintenance.

Resilience

Everkeep connects backup to long-term preservation

Backup is only one part of continuity. Everkeep represents the broader expectation that important information remains recoverable, portable, understandable, and transferable even as applications and infrastructure change.

Browser

A dedicated home for GoreeCloud Firefox extensions

GoreeCloud Browser remains a Firefox-based privacy project, while GoreeCloud-maintained Firefox extensions now have a dedicated source-control home so browser integrations can be versioned and maintained independently.

History

Preserving the story behind the platform

Changelogs, the public Archive, the Blog, and the Autobiography project are complementary ways to preserve technical history, decisions, lessons, and the long-term evolution of GoreeCloud.
