Platform

GoreeCloud is becoming a software ecosystem

The project now spans a growing Suite of native applications and maintained forks, connected by Glaze UI, Wardveil Security, Privacy Shield, Everkeep, and shared interoperability rules. The goal is not to reproduce a commercial cloud vendor—it is to preserve ownership, portability, and control.

Products

New first-party application families

Mail, Music, Photos, Tasks, DNS, Network, and Keyboard now have focused product or capability identities such as Courier, Resonance, Keepsake, Waypoint, Beacon, Conduit, and Quill. These names organize features without replacing the applications themselves.

Design

Glaze UI across mobile, tablet, desktop, and TV

Glaze UI is evolving from a visual style into a cross-form-factor interaction system with deliberate adaptation, accessibility, stable semantics, and controlled expression.

Development

Fork when useful. Build native when it matters.

GoreeCloud uses open-source foundations pragmatically while steadily increasing first-party ownership of interfaces, capabilities, data contracts, release engineering, and long-term maintenance.

Resilience

Everkeep connects backup to long-term preservation

Backup is only one part of continuity. Everkeep represents the broader expectation that important information remains recoverable, portable, understandable, and transferable even as applications and infrastructure change.
