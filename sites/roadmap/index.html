Public Development Roadmap · August 29, 2026

From a homelab into an owned software ecosystem.

GoreeCloud is moving from a collection of self-hosted tools toward a cohesive personal and family cloud whose GoreeCloud application layer is original, native-from-the-ground-up software. Mature technical foundations can remain where replacing them would materially increase security, standards, protocol, codec, rendering, runtime, or interoperability risk. This public roadmap is intentionally higher level than internal task tracking: dates are not promises, priorities may change, and private infrastructure or security-sensitive work is omitted.

Now

Active development

Work already underway across the platform.

Production

Public web ecosystem

Ten focused public destinations cover the main GoreeCloud site, Suite, Projects, Design Center, Privacy Center, Security Center, Continuity Center, Roadmap, Blog, and Archive. The current phase modernizes information, accessibility, navigation, responsive behavior, approved visual assets, and cross-site consistency against the reviewed 56-repository inventory.

Stable design target

Glaze UI 2.0.0

Glaze UI 2.0.0 is the current Stable production design target. The current material hierarchy is Canvas, Surface, Soft Glaze, Glaze, Deep Glaze, and Live Glaze, with 48px minimum interaction targets, reduced-effects fallbacks, adaptive layouts, and accessibility requirements. Glaze UI 2.1 remains Candidate and is not a Stable consumer-conformance target.

Platform model

Six substantive platform systems

Glaze UI, Privacy Shield, Wardveil Security, Everkeep, GoreeCloud Mesh, and GoreeCloud Identity are substantive systems with distinct authority. Design, privacy, security, continuity, coordination, identity, authentication, authorization, and related public claims remain tied to actual implementation and applicable evidence.

Mandatory direction

Native application program

Every GoreeCloud application has the same required end state: original GoreeCloud-owned software at the product and application layer. Maintained forks and adopted complete application codebases are transitional migration, compatibility, testing, historical, or reference sources only. Production continuity is preserved until replacements satisfy separate migration and acceptance gates.

Active development

GoreeCloud AI and Search

GoreeCloud AI develops as the first-party conversation, workspace, knowledge, RAG, research, file, tool, and orchestration application. GoreeCloud Search remains the first-party search and research gateway. Runtime and provider choices stay bounded implementation details rather than permanent product identity.

Active development

GoreeCloud Code

GoreeCloud Code is the first-party developer and source-control platform for repositories, collaboration, CI/CD, packages, security, and AI-assisted development. Forgejo is an initial replaceable infrastructure foundation rather than the permanent GoreeCloud product boundary.

Active development

GoreeCloud Mesh and Identity

Mesh coordinates explicit service relationships, capability context, governance, lifecycle events, and evidence-aware interoperability. GoreeCloud Identity owns identity, authentication, authorization, accounts, devices, credentials, sessions, and delegated authority. Mesh can coordinate Identity relationships but cannot replace Identity authority.

Active development

Suite expansion

Documents, Messenger, Gateway, Quill, File Manager, Maps, App Store, Drive, Sync, Location, Launcher, Mail, Notes, Tasks, Calendar, Contacts, Photos, Music, Video, and other focused applications continue advancing without collapsing into one oversized cloud product.

Active development

App Store, File Manager, and Maps

GoreeCloud App Store is developing as the official multi-user application and service catalog with account-aware access. File Manager is the first-party file-management experience for local and connected storage surfaces. Maps is the mapping experience with explicit privacy, location, navigation, and identity boundaries. Public artwork remains limited to approved canonical assets.

Evidence-gated

Security, privacy, and continuity

Wardveil Security, Privacy Shield, and Everkeep continue production-oriented work while their public Centers stay evidence-scoped. A website label or platform name cannot manufacture protection, privacy, recovery, preservation, or continuity state without applicable current implementation and evidence.

Active development

Drive, Sync, Documents, and personal context

Drive, Sync, Documents, Location, Contacts, Calendar, Tasks, Notes, and related applications continue developing focused data models, authorization boundaries, portability, recovery, collaboration, and interoperability rather than re-creating a single all-in-one cloud suite.

Current identity

Facet and unified branding assets

Facet is the current official Glaze UI identity. GoreeCloud logos, product icons, system marks, artwork, and derivatives are sourced from the current approved branding authorities. Products without an approved canonical asset use neutral presentation rather than fabricated official artwork.

Next

Near-term priorities

Publicly relevant work expected to follow current foundations.

Planned

Source-native Glaze UI adoption

Remove remaining legacy 1.x source transforms and generated leftovers so official websites consume Glaze UI 2.0 Stable directly and validators enforce responsive, accessibility, provenance, and truth-boundary requirements.

Planned

GoreeCloud Code authority transition

Advance repository migration, issues, pull requests, releases, packages, CI/CD, controlled runners, security workflows, and provider-neutral integrations while retaining optional external collaboration and mirrors where useful.

Planned

AI Workspaces and native knowledge workflows

Advance persistent workspaces, document ingestion, embeddings, indexing, retrieval, source attribution, privacy-aware research, tool use, and representative recovery validation without overstating production maturity.

Planned

Integrated Suite experiences

Strengthen deliberate interoperability such as Tasks and Calendar, Drive and Sync, Documents and Drive, Messenger and Contacts, App Store and Identity, Maps and Location, shared notifications, APIs, portability, and current Stable design behavior without unnecessary coupling.

Planned

Native device experiences

Advance Launcher, Keyboard, Quill, Terminal, Browser, Messenger, Maps, and other device software through build, packaging, accessibility, real-device acceptance, and controlled release gates.

Planned

Release, distribution, and public documentation

Make supported versions, release notes, verification guidance, platform packages, approved download paths, public guides, and sanitized architecture explanations easier to understand without exposing private topology or operationally sensitive detail.

Later

Long-term direction

Strategic outcomes rather than scheduled commitments.

Future

Local-first primary infrastructure

Move the center of gravity toward GoreeCloud-owned local systems while preserving resilient remote access, backups, recovery, portability, and safe operating boundaries.

Future

Developer-platform independence

Move normal development, CI/CD, packages, release evidence, repository automation, security workflows, and AI-assisted development behind GoreeCloud Code and GoreeCloud-controlled execution while retaining replaceable infrastructure foundations.

Future

Advanced local AI independence

Expand GoreeCloud AI into justified tools, agents, multimodal capabilities, automation, browser interaction, and local research while keeping models, data, workflows, permissions, and knowledge under GoreeCloud control.

Future

Native product ownership

Complete the transition to original GoreeCloud applications at the product layer while retaining only narrowly justified mature technical dependencies and standards-compatible foundations.

Future

Long-term digital continuity

Keep data, memories, documentation, credentials, software, and operational knowledge portable, recoverable, understandable, and transferable across changing technologies.
